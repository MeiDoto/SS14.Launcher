## 🎨 Визуальные темы и оформление интерфейса

Встроенный кастомизатор оформления (`Настройки` -> `Персонализация` или диалог кастомизации) предоставляет богатые возможности стилизации:

### 1.1. Настройка цветовой палитры
Пользователь может задать шестнадцатеричные (HEX) цвета, которые динамически обновляют словарь ресурсов Avalonia:
- **Акцентный цвет** (`CustomAccentColor`): Базовый брендовый цвет кнопок, активных вкладок и переключателей.
- **Цвет акцента при наведении** (`CustomAccentHoverColor`): Интерактивные состояния элементов.
- **Фон главного окна** (`CustomWindowBgColor`): Основной тон подложки интерфейса.
- **Цвет карточек** (`CustomCardBgColor`): Фон списков серверов, панелей и модальных окон.
- **Цвет текста** (`CustomTextColor`): Контрастная типографика.

### 1.2. Фоновые изображения и визуальные эффекты
- **Пользовательские обои**: Поддерживаются форматы изображений `.png`, `.jpg` и `.webp`.
- **Прозрачность фона**: Регулировка степени наложения фонового изображения на карточки от 0% до 100%.
- **Радиус размытия (Blur Radius)**: Аппаратное размытие по Гауссу для сохранения читаемости текста поверх детализированных обоев.

### 1.3. Расположение панели навигации
Параметр `TabStripPlacement` позволяет изменить расположение меню:
- **Сверху**: Классическое десктопное горизонтальное меню.
- **Слева**: Вертикальный сайдбар для широкоформатных мониторов 16:9 и 21:9.
- **Снизу**: Удобный компактный режим для портативных устройств (Steam Deck и др.).

## 🚀 Оптимизация производительности игры

Раздел **Настройки** -> **Производительность игры**:

### 2.1. Повышенный приоритет процесса
Повышает системный приоритет процесса игры до `AboveNormal` или `High` (`ProcessPriorityClass.High` на Windows, `nice -n -10` на Linux/macOS). Это гарантирует плавность кадров и защиту от микрофризов при фоновой нагрузке в ОС.

### 2.2. Принудительное использование дискретного GPU
Для ноутбуков с гибридной графикой (Intel/AMD iGPU + NVIDIA/AMD dGPU):
- **Linux**: Передает оптимизированные флаги `DRI_PRIME=1`, `__NV_PRIME_RENDER_OFFLOAD=1` и `__GLX_VENDOR_LIBRARY_NAME=nvidia`.
- **Windows**: Регистрирует профиль приложения DirectX для автоматического переключения на производительный видеоадаптер.

### 2.3. Оптимизации трехуровневого JIT (Tiered PGO)
Включает расширенные флаги среды выполнения .NET:
- `DOTNET_TieredPGO=1`: Динамическая оптимизация по результатам профилирования.
- `DOTNET_TC_QuickJitForLoops=1`: Ускоренная компиляция циклов для быстрой загрузки игровых карт.

### 2.4. Пользовательские аргументы запуска и переменные окружения
Во вкладке **Разработка** можно указать дополнительные флаги командной строки (например, `--cvar display.vsync=false`) или определить переменные окружения (`ROBUST_SOUNDFONT_OVERRIDE=...`).

## 🛠️ Инструменты для разработчиков и хостеров

### 3.1. Подключение сторонних хабов
Серверные сообщества могут указывать собственные URL хабов в `CVars.HubUrls`. Серверы автоматически встраиваются в общий браузер серверов с поддержкой поиска, тегов и замера пинга.

### 3.2. Переопределение сборок движка и контента
Для тестирования локальных изменений:
- **Переопределение движка**: Указание пути к локальной сборке DLL Robust вместо скачивания с CDN.
- **Переопределение контента**: Запуск клиента напрямую из рабочей копии Git без упаковки zip-манифестов.

### 3.3. Просмотр реплеев и встроенный просмотрщик логов
- **Вкладка реплеев**: Анализ, сортировка и запуск записей раундов (`.zip`), сохраненных на диске.
- **Встроенный просмотрщик журналов**: Полнотекстовый поиск по логам Serilog в реальном времени с фильтрацией по уровням (`Verbose`, `Debug`, `Info`, `Warning`, `Error`) и быстрым копированием диагностических данных.
