# 🧪 Тестовый стенд Fake Robust.Client

[🇬🇧 Read in English](README.md) | [🇷🇺 Читать на русском](README.ru.md)

`SS14.Launcher.FakeRobustToolbox` — легковесный стенд для разработки и интеграционного тестирования, имитирующий запуск клиента игры, вызовы `Robust.LoaderApi` и протокол обратной связи клиента с лаунчером без необходимости компиляции или скачивания реального клиента Space Station 14.

---

## 🎯 Назначение и архитектура

1. **Проверка API загрузчика (`Robust.LoaderApi`)**:
   Реализует интерфейс `ILoaderEntryPoint` с атрибутом сборки `[assembly: LoaderEntryPoint(typeof(Robust.Client.FakeClient))]`.
   При старте лаунчер загружает сборку движка, находит точку входа через рефлексию и передает управление в метод `Main(IMainArgs args)`.
2. **Тестирование протокола переподключения (Redial API)**:
   Проверяет интерфейс лаунчера `RedialApi` (`IMainArgs.RedialApi.Redial(Uri, string)`). Фейковый клиент эмулирует редиал на адрес `ss14://localhost:1212` с многострочным сообщением причины, позволяя тестировать обработку переподключений и всплывающие окна в UI лаунчера.
3. **Локальный эмулятор HTTP-сервера**:
   Каталог `server/` содержит вспомогательные скрипты и файлы (`/status`, `/info`), имитирующие ответы игрового сервера SS14.

---

## 🚀 Сборка и запуск стенда

### 1. Сборка фейкового клиента
```bash
cd SS14.Launcher.FakeRobustToolbox
dotnet build
```

### 2. Упаковка и установка тестовой версии движка
Скрипт `server/run` упаковывает собранную библиотеку в zip-архив с именем `meme.zip` и копирует в каталог движков локального лаунчера:

```bash
cd server
chmod +x run
./run
```

Скрипт выполняет следующие действия:
1. Компилирует `Robust.Client.dll`.
2. Упаковывает библиотеку в архив `client.zip`.
3. Копирует архив в `~/.local/share/Space Station 14/launcher/engines/meme.zip`.
4. Запускает локальный веб-сервер на порту `1212`, отдающий статус игрового сервера.

### 3. Подключение через лаунчер
В лаунчере настройте переопределение версии движка или подключитесь к адресу `ss14://localhost:1212` для проверки передачи параметров запуска, переменных окружения и обработки редиалов.
